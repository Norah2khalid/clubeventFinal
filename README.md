# ابتكار حلول رقمية لمواجهة التضليل الإعلامي

موقع فعالية جامعة الجوف، بالعربية واتجاه من اليمين إلى اليسار. الهوية البصرية والحركة مأخوذتان من مشروع Lovable: الألوان البنفسجية، خطا IBM Plex Sans Arabic وTajawal، وبطاقات الأقسام نفسها.

## التشغيل

```sh
cp .env.example .env
pnpm install
pnpm dev
```

شجرة الاعتماديات الحالية تتعطل مع npm 10. استخدم pnpm، أو npm 11 فما فوق.

المفتاح في ملف البيئة مفتاح عام للواجهة. لا تضع مفتاح الخدمة أو أي مفتاح يبدأ بـ `sb_secret` في ملفات الواجهة أو Git.

## ما يراه المشارك

- الصفحة الرئيسية، آلية المشاركة، التحديان، مشاركات الفعالية، أهداف الفعالية، وأثر الحلول الرقمية.
- لكل مشكلة في التحدي الأول مشاركة، وللتحدي الثاني مشاركة لتطوير التطبيقات وأخرى لتطوير المساعدات الذكية.
- داخل المشاركة يبقى البرومبت الإرشادي كما هو للنسخ إلى أداة ذكاء اصطناعي خارجية. الموقع لا يخترع الفكرة ولا يستبدلها.
- «رفع المشاركة» يحفظ نص الفكرة في جدول `participations`. اسم الفكرة هو السطر الأول من النص.
- باركود «امسح الباركود» يظهر فقط إذا ربطت المنظِّمة صورة منشورة بهذه المساعدة.
- قسم «مشاركات الفعالية» يعرض المشاركات المحفوظة. بوكسا الفكرتين الفائزتين يبقيان فارغين حتى تختار المنظِّمة فائزتين.

## لوحة المنظِّمة

المسار `/admin` محمي بتسجيل الدخول وصلاحية المسؤول، وليس بإخفاء الرابط.

1. عطّل التسجيل العام في Supabase Auth.
2. أنشئ حساب المنظِّمة من لوحة Supabase.
3. نفّذ ملفات `drizzle/migrations` بالترتيب في محرر SQL إن لم تكن مطبّقة. `0002` ينشئ مساحة التخزين `event-barcodes`، و`0003_participations.sql` ينشئ جدول المشاركات وسياساته ودالة اختيار الفائزين.
4. أول حساب يسجّل الدخول يحصل على دور المسؤول عبر `claim_first_admin()` ما دام لا يوجد مسؤول بعد. الحسابات التالية لا تملك صلاحية.

من لوحة `/admin` يمكن رفع صور PNG وJPG وJPEG، وربط كل باركود بمساعدة، ومعاينته وتعديله واستبدال صورته وإظهاره أو إخفاؤه وتنزيل الملف الأصلي وحذفه. الزائر لا يستطيع الرفع أو التعديل أو الحذف؛ سياسات RLS تسمح بقراءة الباركودات المنشورة فقط.

بعد تسجيل الدخول كمسؤول، ارجعي إلى قسم «مشاركات الفعالية» في الصفحة الرئيسية. أزرار الترقية والحذف تظهر للحساب صاحب دور `admin` فقط، وقاعدة البيانات ترفضها من أي حساب آخر حتى لو أُخفيت الأزرار.

## النشر على Vercel

البناء ينتج `.vercel/output` عبر Nitro preset `vercel`. لا تضبط مجلد الإخراج في لوحة Vercel؛ المنصة تقرأ Build Output API من هذا المسار.

1. استورد المستودع في Vercel. مدير الحزم يُكتشف من `pnpm-lock.yaml`.
2. أمر البناء: `npm run build`. إطار العمل يبقى فارغًا (`framework: null` في `vercel.json`).
3. أضف متغيرات البيئة قبل البناء، لأن Vite يدمج قيم `VITE_` أثناء البناء:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_PUBLISHABLE_KEY`
   - `SUPABASE_URL`
   - `SUPABASE_PUBLISHABLE_KEY`
4. لا تضف مفتاح الخدمة. ثم انشر.
