# ابتكار حلول رقمية لمواجهة التضليل الإعلامي

موقع فعالية جامعة الجوف، بالعربية واتجاه من اليمين إلى اليسار. الهوية البصرية والحركة مأخوذتان من مشروع Lovable: الألوان البنفسجية، خطا IBM Plex Sans Arabic وTajawal، وبطاقات الأقسام نفسها.

## التشغيل

```sh
cp .env.example .env
pnpm install
pnpm dev
```

شجرة الاعتماديات الحالية تتعطل مع npm 10. استخدم pnpm، أو npm 11 فما فوق.

المفتاح في ملف البيئة مفتاح عام للواجهة. لا تضع مفتاح الخدمة أو أي مفتاح يبدأ بـ `sb_secret` في ملفات الواجهة أو Git.

## ما يراه المشارك

- الصفحة الرئيسية، آلية المشاركة، التحديان، أهداف الفعالية، وأثر الحلول الرقمية.
- لكل مشكلة في التحدي الأول مساعدة إرشادية، وللتحدي الثاني مساعد لتطوير التطبيقات وآخر لتطوير المساعدات الذكية.
- المساعدة تجهّز برومبتًا مخصصًا لفكرة المشارك لينسخه إلى أداة ذكاء اصطناعي خارجية. الموقع لا يخترع الفكرة ولا يستبدلها.
- باركود «امسح الباركود» يظهر فقط إذا ربطت المنظِّمة صورة منشورة بهذه المساعدة.

## لوحة المنظِّمة

المسار `/admin` محمي بتسجيل الدخول وصلاحية المسؤول، وليس بإخفاء الرابط.

1. عطّل التسجيل العام في Supabase Auth.
2. أنشئ حساب المنظِّمة من لوحة Supabase.
3. نفّذ ملفات `drizzle/migrations` بالترتيب في محرر SQL إن لم تكن مطبّقة. آخر ملف ينشئ مساحة التخزين الخاصة `event-barcodes`.
4. أول حساب يسجّل الدخول يحصل على دور المسؤول عبر `claim_first_admin()` ما دام لا يوجد مسؤول بعد. الحسابات التالية لا تملك صلاحية.

من اللوحة يمكن رفع صور PNG وJPG وJPEG، وربط كل باركود بمساعدة، ومعاينته وتعديله واستبدال صورته وإظهاره أو إخفاؤه وتنزيل الملف الأصلي وحذفه. الزائر لا يستطيع الرفع أو التعديل أو الحذف؛ سياسات RLS تسمح بقراءة الباركودات المنشورة فقط.
